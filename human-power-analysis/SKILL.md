# Skill 1：组织权力动态分析

> 人篇章（软技能线）Skill 1 · 底层操作系统见 [`human-social-engineering`](../human-social-engineering/)（Skill 0）。

## 一、定位

诊断组织中的**权力来源、信息流向、联盟结构、心理契约**，输出个人防御策略。
不是教权谋，是看懂结构之后不被当枪、不被消耗、不被边缘。

## 二、触发场景

- 空降领导、汇报线调整、隔级约谈；
- 绩效被压、老员工不服、跨部门博弈；
- 感觉“事情不对但说不清哪里不对”，需要先画清结构再行动。

## 三、核心动作

1. **画权力地图**：正式权力 vs 实际权力 vs 信息枢纽；
2. **识别策略**：斩首、招安、架空、稀释、信息控制、制度包装、选择性施恩、分化、测试；
3. **判断稳定机制**：真认同 / 被动适应 / 恐惧抑制 / 分化自保 / 等待变化；
4. **评估自己的风险**：被当枪、被站队、被消耗、被边缘、被审查、被拉拢；
5. **输出防御策略**：不站队、不传话、双线透明、成果留痕、边界管理。

## 四、关键话术

> “谢谢领导告诉我这些，我会认真复盘，下半年把该提升的地方做好。”

（不对抗、不站队、不接暗示；把话题收回到“我会做好本职工作”。）

## 五、红线

- 不挑拨、不越级告状；
- 不参与旧团队对抗；
- 不传播敏感信息。

## 六、与 Skill 0 的关系

权力分析的每一条判断，底层都是 Skill 0 的三根支柱：**感知谁有实权、信息如何被框架、归因被谁拿走**。看结构（Skill 1）之后若陷入自我怀疑，接 Skill 8 情绪定位。
