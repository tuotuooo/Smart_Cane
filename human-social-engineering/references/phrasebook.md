# 框架应对话术库：场景 → 回法

> 遇到问题来查判据用。**不适用**：对方是真诚提问而非框架指控时——那就正常回答，别套模板。
> 关联文档：`../SKILL.md`（三支柱与四步流程）

---

## 一、先记住这几句

1. **不否认动机，转成条件。** 对方说"你要钱"，别辩"我不是要钱"，说"钱是项目条件，您说给就把额度范围节点定下来"。
2. **不证明自己，请对方决策。** 对方说"汇报差点意思"，别解释，说"请指一个最优先改的点，或给我一版示范"。
3. **不接评价题，给选择题。** 把"你怎么这么计较"换成"您定标准，我按标准来"。
4. 所有回法的共同结构：**承认信息 → 转成项目语言 → 给选项 → 请对方拍板。**

---

## 二、完整场景对照表

| 场景 | 对方框架 | 回法 | 底层动作 |
|------|---------|------|---------|
| 被说"你不就是要钱" | 把项目条件框架成个人诉求 | "钱是项目条件，不是个人诉求。您说给，我们把额度、范围、节点定下来。" | 转条件 |
| 被说"汇报差点意思" | 模糊否定，无标准 | "请指一个最优先改的点，或给我一版示范，我照着改。" | 要标准 |
| 被说"多而杂" | 否定结构而非内容 | "明白，我收窄到旗舰，先出 5 页骨架您看方向。" | 给最小验证 |
| 被说"你乱接活" | 把记录责任框架成承诺 | "这些需求来源是 X 部门，我只记录未承诺。后续按什么标准接，请您定规则。" | 划边界 + 请拍板 |
| 客户怕装远程 | 把协助框架成侵入 | "只收集日志，您全程可见，用完可卸载。您看今天下午还是明天上午方便？" | 降风险 + 给选项 |
| 跨部门加急 | 把插队框架成义务 | "可以帮，但会影响 A 的交付。请确认 C 的优先级，以及是否接受 A 延期。" | 让成本可见 |
| 被要求站队/传话 | 把你框架成阵营的人 | "我和两边都有工作配合，具体评价我不适合说，我更关注把手上的事做好。" | 拒框架不拒人 |

## 三、判据：什么时候用哪根支柱

| 现象 | 判读 | 用哪根支柱 |
|------|------|-----------|
| 活干了但没被提 | 感知没被设计 | 支柱一：让成本/边界/价值可见 |
| 成果变成"团队的"、锅是你的 | 归因不清 | 支柱二：留痕 + 责任明确 |
| 被说动机（要钱/计较/不专业） | 框架被对方拿走 | 支柱三：转条件 + 请决策 |
| 对方只给否定不给选项 | 评价题陷阱 | 第三步：把证明题换成选择题 |
| 口头说完就忘/被曲解 | 感知衰减 | 第四步：书面留痕 |

## 四、坑

### 4.1 把防御做成攻击

**现象**：用了话术，但语气带刺、把对方也框了一道。
**后果**：框架免疫变成挑衅，关系受损，比不用更糟。
**正解**：话术只用于**准确呈现 + 边界管理 + 风险告知 + 决策请求**，不带情绪、不贴标签。

### 4.2 对真诚问题套模板

**现象**：对方真的在问"这个方案怎么做"，你回"请您定标准"。
**后果**：显得敷衍、不专业。
**正解**：先判断是框架指控还是真诚提问——后者直接给答案。

### 4.3 只说不留痕

**现象**：口头把边界说清楚了，没写纪要。
**后果**：事后对方不认，归因又被吸走。
**正解**：面谈补纪要、风险走邮件、成果进周报，书面才留得住。
