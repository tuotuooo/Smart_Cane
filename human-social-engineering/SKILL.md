# Skill 0：社会工程学感知与框架管理

> **这是"人篇章"的 Skill 0，也是前面所有组织行为学 / 防御策略 Skill 的底层操作系统。**
> 前面 8 个偏组织行为学和防御策略，但社会工程学的那根"总筋"没有单独拎出来。如果只保留一个最重要的社工 Skill，不是"话术"，也不是"读心"，而是——**感知—归因—框架管理**：让别人准确感知你的成本、边界和价值，同时不被别人的框架带走。

---

## 一、为什么它最重要

社会工程学的核心事实：

> **人不是对事实做反应，而是对"被呈现的事实"做反应。**

同样一个帮助行为：
- 领导做，被感知为"恩惠"；
- 你做，被感知为"本分"。

同样一个资源需求：
- 你说"我要预算"，被框架成"你要钱"；
- 你说"项目要条件，请您选方案"，被框架成"你在做管理决策"。

同样一个风险：
- 你写"出问题我们不管"，客户感知为"推责"；
- 你写"支持边界在此，建议走渠道售后"，客户感知为"专业告知"。

**你吃亏，往往不是事做错了，而是感知没被设计、归因没被引导、框架被对方拿走了。**

## 二、三根支柱

### 支柱一：感知管理——让成本、边界、价值可见

别人不会自动看见你的付出。你要让三样东西进入对方感知：

- **成本可见**：你为此调整了什么优先级、垫了什么、承担了什么风险；
- **边界可见**：你能做什么、不能做什么、什么需要对方决策；
- **价值可见**：节省多少时间、降低什么风险、覆盖多少人、能否复用。

**不是邀功，是信息同步。** 不说，对方就默认"你顺手做的"。

### 支柱二：归因设计——让成果有名字，让责任有归属

- 成果要留痕：文档、纪要、周报、复盘，写"谁做了什么、产生什么结果"；
- 责任要明确：风险单列、售后指向明确路径、决策请对方拍板；
- 不抢功，但也不让功被默认吸走：领导挂名在前，你落名在后。

**归因不清，成果就会变成"团队的"，责任就会变成"你的"。**

### 支柱三：框架控制——不接对方的框架，给回选择题

对方常用框架：

- "你不就是要钱吗？"
- "你汇报差点意思。"
- "你怎么这么计较？"
- "别人怎么不像你？"
- "你先做出来再说。"

**不要自证，不要辩解动机。** 把框架换回项目语言：

> "钱是项目条件。您说给，那我们把额度、范围、节点定下来。"
> "请指一个最优先改的点，或给我一版示范。"
> "我只说这个项目的实际条件，请您按这个项目定。"
> "当前版本已可演示，扩展需要您定最小验证额度。"

**核心句式：不否认动机，转成条件；不证明自己，请对方决策。**

## 三、操作流程：四步

### 第一步：识别对方在用什么框架

问自己：

- 他把我的行为定义成什么？要钱？计较？不专业？不稳定？
- 他把责任归给谁？我？团队？流程？
- 他给了什么选项？还是只给否定？

### 第二步：把事实翻译成对方能结算的单位

- 对领导：需求、成本、风险、收益、待决策；
- 对客户：支持边界、建议路径、售后归属；
- 对跨部门：优先级、资源、影响、谁拍板。

**技术语言翻译成管理语言，管理语言翻译成决策选项。**

### 第三步：给选项，不给证明题

- 暂停 / 最小验证 / 完整推进；
- 远程 / 自助采集 / 上门；
- 先做 A / 先做 B / 替换一项。

**让对方选边界，而不是让他评价你。**

### 第四步：留痕，锁住感知和归因

- 面谈后补纪要；
- 汇报后写确认；
- 风险沟通走邮件；
- 成果进周报和复盘。

**口头感知会衰减，书面归因才留得住。**

## 四、关键话术库

完整场景→话术对照表见 [`references/phrasebook.md`](references/phrasebook.md)。高频几条：

| 场景 | 话术 |
|------|------|
| 被说"你不就是要钱" | "钱是项目条件，不是个人诉求。您说给，我们把额度、范围、节点定下来。" |
| 被说"汇报差点意思" | "请指一个最优先改的点，或给我一版示范，我照着改。" |
| 客户怕装远程 | "只收集日志，您全程可见，用完可卸载。您看今天下午还是明天上午方便？" |
| 跨部门加急 | "可以帮，但会影响 A 的交付。请确认 C 的优先级，以及是否接受 A 延期。" |
| 被要求站队/传话 | "我和两边都有工作配合，具体评价我不适合说，我更关注把手上的事做好。" |

## 五、红线

- 不造假数据、不虚构成果；
- 不挑拨离间、不传播隐私；
- 不越级抢功、不冒充承诺；
- 不用"感知管理"去欺骗、诱导、打压他人；
- 只做**准确呈现、边界管理、风险告知、决策请求**。

> 这个 Skill 是防御性的"框架免疫"，不是攻击性的"操控他人"。红线不是附加条款，是使用前提。

## 七、一句话总纲

> **最重要的社工 Skill 不是操控人，而是管理"感知—归因—框架"：让你的成本、边界和价值被准确看见；让成果有名字、责任有归属；不接对方的动机指控，把话题拉回条件和选项；最后用书面留痕锁住它。**

**你不需要更会说话，你需要让事实以对方能结算的方式出现，并且不被对方的框架定义。**
