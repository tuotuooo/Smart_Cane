# Skill 3：向上汇报结构化

> 人篇章（软技能线）Skill 3 · 底层操作系统见 [`human-social-engineering`](../human-social-engineering/)（Skill 0）。

## 一、定位

把“我干了什么”的流水账，改成“**听众为什么要关心、带来了什么价值**”的价值叙事。
汇报不是过程放映，是价值交付。

## 二、触发场景

- 周报、年末总结、项目复盘；
- 培训 PPT、跨部门汇报；
- 任何“内容很多但不知道怎么讲”的场合。

## 三、核心动作

1. **先定三问**：听众是谁、讲多久、最想让他们记住一件事；
2. **五段结构**：结论 → 成果与影响 → 风险与偏差 → 待决策 → 下一步；
3. **why 和 value 重点讲，process 简述**：过程只留关键节点、关键决策、关键风险；
4. **专业深度按听众分配**：业务听结论和场景，技术听实现和边界，管理层听价值和风险；
5. **第一版只给 5 页骨架**，不给全文，让领导先选方向。

## 四、关键话术

> “我按'为什么—过程简述—结果—价值'来组织，重点放在为什么和价值，专业细节一句话带过、放附录，您看可以吗？”

（先让对方选方向，再展开全文——这正是 Skill 0 的“给选项不给证明题”。）

## 五、红线

- 不按时间线从头讲；
- 不把辛苦当价值；
- 不在业务面前堆技术细节。

## 六、与 Skill 0 的关系

“why 和 value 重点讲”就是 Skill 0 的**感知管理**——让价值进入对方能结算的单位；“5 页骨架先选方向”就是**框架控制**——不让对方在你展开之后才否定方向。定完结构后用 Skill 2 做发前审稿。
