# Skill 8：职场情绪与自我定位

> 人篇章（软技能线）Skill 8 · 底层操作系统见 [`human-social-engineering`](../human-social-engineering/)（Skill 0）。

## 一、定位

把“他是不是不认可我”的自我怀疑，转成“**结构问题 + 可执行动作**”，减少内耗。
你的技术价值，不由别人的额度决定。

## 二、触发场景

- 烧心、委屈、被 PUA 后自我怀疑；
- 付出被理所当然化、评价权被拿捏；
- 持续内耗，不知道该不该继续投入。

## 三、核心动作

1. **区分“认可”和“给资源”**：60 分认可不会触发 85 分投入，不是你不值；
2. **区分“管理惰性”和“结构性压制”**：看是否只否定、不示范、不认改进、伴随贬低；
3. **不把自我价值押在审批上**：他给额度是加速器，不给也不停止积累证据；
4. **把情绪转成动作**：小步验证、提前约定触发条件、不给资源就让他排序；
5. **建立可迁移证据**：案例、量化收益、技术文档、跨部门记录；
6. **评估退出时机**：长期自费、自扛、成果被归因、资源不给、PUA 不断，就不是沟通问题。

## 四、关键话术（对自己说）

> “我的技术价值不由他的额度决定。他给，是加速器；他不给，我也不会停止积累证据。”

（把评价权从对方手里拿回来，换成可迁移的证据。）

## 五、红线

- 不内化“你不行”的标签；
- 不用自我燃烧换认可；
- 不把“不报销”当抗议。

## 六、与 Skill 0 的关系

Skill 0 说“不把对方框架内化成自我评价”，本 Skill 是这条在**情绪层面**的执行版：把“他不认可我”这个框架，换成“结构问题 + 我下一步做什么”。看不清结构时先用 Skill 1 权力分析。
