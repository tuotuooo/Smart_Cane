# Skill 4：资源申请与反 PUA

> 人篇章（软技能线）Skill 4 · 底层操作系统见 [`human-social-engineering`](../human-social-engineering/)（Skill 0）。

## 一、定位

把“我要钱 / 要资源”转成“**请您做项目条件决策**”，不接动机指控。
钱是项目条件，不是个人诉求——一旦被框架成“你要钱”，就永远在自证。

## 二、触发场景

- 申请预算、要求额度；
- 拒绝自费垫付；
- 被说“你不就是要钱吗”“你怎么这么计较”。

## 三、核心动作

1. **先合规筛查**：敏感用途单独剔除，不混进报销；
2. **总额 + 清单 + 估算原则**：不假装精确分摊；
3. **给选项不给账单**：暂停 / 最小验证 / 完整推进；
4. **不接帽子**：不否认动机，转成项目语言；
5. **顺水推舟**：他说给，就请他落额度、范围、节点、责任；
6. **留痕**：面谈后补微信纪要。

## 四、关键话术

> “钱是项目条件，不是个人诉求。您说给，那我们把额度、范围和节点定下来，我按这个执行。”

（不辩解动机，把“给不给”变成“给的话请拍板条件”。）

## 五、红线

- 不自费兜底；
- 不虚构用途；
- 不用“不报销”表达抗议；
- 不威胁停摆。

## 六、与 Skill 0 的关系

这是 Skill 0 **框架控制**最典型的应用：对方给的是“你要钱”的动机框架，你换回“项目条件”的决策框架。清单发出前用 Skill 2 预审，避免又变回“账单”。
